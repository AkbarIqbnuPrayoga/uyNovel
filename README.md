# UYNovel

**UYNovel** is a webtoon browsing platform featuring a distinctive brutalist design and an interactive interface for discovering comics. The project integrates the Webtoons API to display webtoon-related data in a streamlined browsing experience.

### Features

- **Webtoon Search** — Search for webtoon titles through the website interface.
- **Trending Now** — A dedicated section for discovering trending webtoon content.
- **Webtoons API Integration** — Retrieve webtoon-related data through API integration.
- **Brutalist UI Design** — A bold, distinctive visual style with a minimalist layout.
- **Interactive Interface** — Simple navigation for browsing and discovering webtoon content.

### Live Demo

https://uynovel.vercel.app/

### Project Goals

UYNovel aims to provide a straightforward webtoon discovery experience by combining API-driven content with a distinctive visual identity and accessible web interface.
